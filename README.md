# project-about-Power-Bi
💼 Sales Banking Dashboard | Power BI

Developed an interactive Sales Banking Dashboard using Power BI to analyze and visualize key sales metrics for banking operations.

Key Highlights:

Data cleaning, transformation, and modeling using Power Query & DAX.

KPIs: Total Sales, Orders, Product Cost, Sales Quantity.

Insights: Top-performing company, best month by sales & orders, highest cost period.

Visuals: Donut Chart, Bar Chart, Sparkline Chart, and Interactive Slicers for dynamic analysis.
